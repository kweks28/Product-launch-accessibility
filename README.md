Product Launch Accessibility Fixes
University Assignment: Web Accessibility & Usability

Project Overview
University assignment to fix accessibility issues on a product launch page and achieve WCAG 2.1 AA compliance.

Live Demos
- Original (Before): https://kweks28.github.io/Product-launch-accessibility/product_launch.html
- Fixed (After): https://kweks28.github.io/Product-launch-accessibility/product_launch_fixed.html

Accessibility Improvements
✅ Document Structure: Added `lang="en"`, proper headings, ARIA landmarks  
✅ Forms & Labels: All form controls have proper labels and fieldset/legend  
✅ Color Contrast: Fixed all contrast issues (>4.5:1 ratio)  
✅ Keyboard Navigation: Full keyboard support with visible focus indicators  
✅ Images & Media: Descriptive alt text, accessible YouTube video  
✅ JavaScript:Accessible dynamic content with screen reader announcements

Testing Results
| Metric | Before | After | Improvement |
|--------|--------|-------|-------------|
| WAVE Score | 6.8/10 | 10/10 | +3.2 points |
| Errors | 14 | 0 | 100% fixed |
| Contrast Errors | 1 |0 | 100% fixed |
| Alerts | 29 | 4 | 86% reduced |

WCAG 2.1 AA Compliance
- 1.1.1 Non-text Content ✓
- 1.3.1 Info and Relationships ✓
- 1.4.3 Contrast (Minimum) ✓
- 2.1.1 Keyboard ✓
- 2.4.2 Page Titled ✓
- 3.3.2 Labels or Instructions ✓
- 4.1.2 Name, Role, Value ✓
